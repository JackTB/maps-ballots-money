# Overview

This project contains multiple sections but the main goal is to contain 
the content for the smallripples.org website found in the public folder.

Outside of the public folder are files used to create the visible pages.

Inside the public folder are following areas:

- Maps Ballots Money
- NC Voter Registration Reports
- NC 2026 Legislative Election Races

# NC 2026 Legislative Election Races

The [Starting page](https://smallripples.org/nc2026.html) links to both maps and tables
of the 2026 NC races for US House of Representatives, NC Assembly Senate, 
and NC Assembly Representatives. The tables start with a single table with a few 
items about each district race. The district numbers are links to a page with more 
details about each race.
