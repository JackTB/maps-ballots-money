Weekly Voter Registration Reports

Each week the NC Board of Elections releases the latest file of registered voters. I have not found a good way to see historic data, so I started keeping my own.

My naming convention is to use the year and week number, so 2026 week 41 would appear as 26w41. I have a table showing the start and end date of each week for reference.

I also run a check looking for statistically significant difference in the distribution of the following:

  • Party Registration
  • Voter Gender
  • Voter Race
  • Voter Ethnicity
  • Voter Age Range
  • Voter Registration Status
  • Reason Voter Has Inactive Status
  • Reason Voter Has Removed Status
